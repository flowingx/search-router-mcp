配置与验收

把 Tavily、Keenable、知乎和 Serper 接入同一个本地 MCP。Agent 根据查询主题选择平台，路由器结合额度处理回退。

打开 Agent 提示词手动配置

1. 下载并准备密钥

安装 Python 3.12+。使用知乎时再安装 uvx。

git clone https://github.com/flowingx/search-router-mcp.git
cd search-router-mcp

首次配置时，把 search-keys.env.example 复制为 search-keys.env.local，在本机编辑器填写要启用的服务。已有密钥文件时直接编辑。

  • TavilyTAVILY_API_KEY
  • KeenableKEENABLE_API_KEY
  • 知乎ZHIHU_ACCESS_SECRET
  • SerperSERPER_API_KEY

2. 生成客户端配置

python verify.py
python verify.py --print-config

第一条命令检查 MCP 握手和工具发现。第二条命令按本机路径生成配置，把输出合并到 Codex 的 ~/.codex/config.toml，然后重启 Codex。系统只提供 python3 时，替换命令里的 python。

3. 让 Agent 生成问题并验收

可先用脚本查询状态或试搜。真实搜索可能消耗平台额度。

python verify.py --status
python verify.py --check auto "替换成你的测试问题"

脚本通过后，把下面的提示词发给 Agent，让它直接调用已注册的 MCP，逐家验证并报告实际平台、状态和来源链接。
